# Stock Analyzer — הערכת שווי, בדיקת דוחות וניתוח חדשות

מכניסים סימול → הכלי מושך 10 שנות דוחות שנתיים (10-K) מ-SEC, מריץ כמה מודלי הערכה ומציג **טווח שווי**, מרווח ביטחון, ו"מה המחיר מגלם".

## הרצה

**Windows:** לחיצה כפולה על `run_windows.bat` (בפעם הראשונה מתקין הכל, ~2 דקות).

**ידנית (כל מערכת):**
```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
export SEC_USER_AGENT="PersonalStockResearch you@example.com"   # Windows: set SEC_USER_AGENT=...
streamlit run app.py          # ממשק בדפדפן
python cli.py AAPL            # דוח בטרמינל (מתחרים מזוהים אוטומטית)
python cli.py AAPL --peers MSFT,GOOGL   # מתחרים ידניים
pytest -q                     # בדיקות
```
דורש Python 3.10+. SEC מבקש מייל ליצירת קשר ב-User-Agent (לא נשלח לשום מקום אחר).

## מה המודלים עושים

| מודל | רעיון | מתי משוקלל |
|---|---|---|
| DCF (3 תרחישים) | היוון FCF לא ממונף ל-10 שנים + ערך טרמינלי | חברות עם FCF חיובי (50%) |
| Reverse DCF | איזו צמיחה / מרווח המחיר הנוכחי מגלם | מוצג תמיד, לא משוקלל |
| EPV | רווח תפעולי מנורמל ÷ WACC, ללא צמיחה | 20% |
| מכפילים | P/E, EV/EBITDA, EV/Sales של המתחרים (חציון, רבעונים 25–75) | 30% |
| Residual Income | הון עצמי + ערך תשואה עודפת על ההון | בנקים/ביטוח (SIC 6000–6799) |
| מספר גראהם | √(22.5 × EPS × BVPS) | ייחוס בלבד |

**הנחות ברירת מחדל** (כולן ניתנות לשינוי בממשק):
- צמיחה = CAGR הכנסות 5 שנים (מוגבל ל-5%- עד 25%), 5 שנים ואז דעיכה ליניארית לצמיחה טרמינלית 2.5%.
- מרווח FCF = חציון 5 שנים של (CFO − Capex − SBC + ריבית × (1−מס)) / הכנסות.
- WACC = CAPM (ריבית חסרת סיכון 4.3%, פרמיה 5%, בטא מ-Yahoo) משוקלל עם עלות החוב.

## זיהוי מתחרים אוטומטי
1. **Yahoo Finance** — הענף של החברה (`industryKey`) → החברות המובילות באותו ענף.
2. **גיבוי: SEC** — כל החברות עם אותו קוד ענף (SIC), עם הכנסות מה-frames API של SEC.

מסננים: רק חברות שמדווחות ל-SEC (נסחרות בארה"ב), בלי החברה עצמה ובלי סוגי מניות כפולים (GOOG/GOOGL). מדרגים לפי קרבה בגודל (שווי שוק / הכנסות) ובוחרים 5. אפשר תמיד לדרוס ידנית בסרגל הצד.

| קטגוריה | בדיקה | אדום כאשר |
|---|---|---|
| ציונים | Beneish M-Score | ‎> -1.78 (צהוב מ-‎-2.22) |

חברות פיננסיות: Beneish / Altman / Piotroski לא מחושבים (לא מתאימים לבנקים).

## שלב 3 — חדשות + ניתוח ביקורתי של מודל שפה

**איסוף:**
- **חלונות זמן:** החודש האחרון (עד 15 סיפורים) ועוד 4 חלונות רבעוניים לאורך השנה, עם 5 הסיפורים הדומיננטיים בכל חלון.
- **מקורות:** Google News (חינמי, בלי מפתח). אם מוגדר מפתח Finnhub (חינמי), נוספות גם כתבות עם תקצירים.
- **"דומיננטי"** = סיפור שכלי תקשורת רבים סיקרו (איחוד כותרות דומות), ממקור חזק (Reuters/Bloomberg/WSJ…), גבוה בדירוג הרלוונטיות, ושעוסק בחברה עצמה. רעש אוטומטי ("קרן X קנתה 1,200 מניות…", "תחזית מחיר") מסונן החוצה. הודעות חברה וכתבות דעה מסומנות ככאלה.
- **טקסט מלא:** לכתבות המובילות נשלף קטע של עד 1,500 תווים מגוף הכתבה, והוא נשלח רק למודל. הרבה אתרים חוסמים או נמצאים מאחורי חומת תשלום, ואז המודל מקבל כותרת בלבד ויודע את זה.

**ניתוח (Gemini או Claude — לבחירה):** המודל מקבל את הכתבות ואת התוצאות של שלבים 1–2 (שווי, Reverse DCF, דגלים אדומים) ומחזיר JSON מובנה:
תקציר · המצב כעת · התפתחות לאורך השנה · **חששות** (לפי חומרה, מקושרים לדגלים) · מספרים מול סיפור · נקודות חיוביות · שאלות לחשוב עליהן · נקודת סיכום (כולל "מה ישנה את התמונה" ורמת ביטחון) · ניתוח לכל מקור (סנטימנט, חשיבות, אמינות).

**נגד הזיות:** כל טענה חייבת להפנות למזהה כתבה (S1, S2…). קוד בודק את ההפניות אחרי התשובה ומוחק טענה שמפנה רק למקורות שלא קיימים. מספר הטענות שנמחקו מוצג.

**עלות:** כ-5–10 אלף טוקנים לניתוח. התוצאה נשמרת במטמון ל-24 שעות, כך שהרצה חוזרת לא עולה כסף.

**הגדרה:** המפתחות נשמרים בקובץ `keys.env` שבתיקיית הפרויקט, והאפליקציה וה-CLI טוענים אותו אוטומטית. אל תשתף את הקובץ הזה. אפשר גם להדביק מפתח בסרגל הצד או להגדיר משתנה סביבה.
- **Google Gemini (ברירת מחדל):** מפתח מ-aistudio.google.com/apikey → `GEMINI_API_KEY`. מודלים: `gemini-3.8-flash` (מומלץ), `gemini-3.6-flash`, `gemini-4-argon` (הכי מעמיק, לא בשכבה החינמית), `gemini-3.5-flash-lite`. אם מודל עמוס (503, נפוץ בשכבה החינמית), הכלי מנסה שוב ואז עובר אוטומטית למודל קל יותר, ומציין במסך באיזה מודל השתמש.
- **Anthropic Claude:** מפתח מ-platform.claude.com → `ANTHROPIC_API_KEY`. מודלים: Sonnet, Opus, Haiku.
- **Finnhub (אופציונלי):** `FINNHUB_API_KEY`.

שני הספקים מקבלים את אותו פרומפט ואותה סכמת JSON, ועוברים את אותו אימות מקורות.

**שימוש בקרדיט החודשי של Google AI Pro:**
1. מפעילים את ההטבה ב-developers.google.com/program/my-benefits ובוחרים חשבון חיוב של Google Cloud. מסמנים "Always use this billing account" כדי שהקרדיט יוחל אוטומטית בכל חודש.
2. ב-aistudio.google.com/apikey יוצרים מפתח בפרויקט שמקושר לאותו חשבון חיוב.
3. מומלץ להגדיר תקציב והתראה ב-Google Cloud Billing → Budgets & alerts (למשל 10 דולר), כדי לא לחרוג מהקרדיט.

```bash
python cli.py AAPL --news                        # Gemini (ברירת מחדל)
python cli.py AAPL --news --provider anthropic   # Claude
```

## שלב 4 — ממשק, מטמון, ענן

**דפים:**
- **🔎 ניתוח מניה:**
  - כרטיס "שורה תחתונה": מצב המחיר מול הטווח, מרווח ביטחון, צמיחה שהמחיר מגלם מול צמיחה היסטורית, דגלים, סנטימנט חדשות וחששות מרכזיים.
  - פס טווח ויזואלי.
  - "מה השתנה מאז הבדיקה הקודמת".
  - כפתורים: ★ מעקב, 🔄 רענון, ⬇️ דוח.
- **⭐ רשימת מעקב:** כל המניות עם הבדיקה האחרונה שלהן, עדכון הערכות לכל הרשימה בלחיצה אחת, ופתיחה מהירה של ניתוח.
- **⚖️ השוואת מניות:** 2–4 מניות זו לצד זו, עם כרטיסים, גרף של טווח השווי ביחס למחיר וטבלת מדדים עם הדגשת הטוב ביותר בכל שורה.
- **🔑 הגדרות ומפתח:** בחירת מודל, מפתח עם בדיקה, ומדריך להשגת מפתח Gemini חינמי. למנהל: ניהול רשימת המורשים ורשימת משתמשים.
- **ℹ️ אודות:** המתודולוגיה.

**מטמון חכם:**

| נתון | תוקף |
|---|---|
| מחיר | 15 דקות |
| דוחות | עד שהחברה מגישה דוח חדש (בדיקה כל 6 שעות) |
| חדשות | 6 שעות |
| ניתוח מודל | 24 שעות |

הכפתור 🔄 עוקף את המטמון.

**היסטוריה:** כל ניתוח נשמר, לכל היותר פעם בשעה לכל מניה. ניתוחי חדשות נשמרים בנפרד.

**דוח:** קובץ HTML מעוצב לכל ניתוח. פותחים אותו בדפדפן, ובהדפסה בוחרים "שמור כ-PDF".

**ענן:** התחברות עם Google, גישה רק למיילים מורשים, מסד Postgres חינמי. **מדריך מלא ב-[DEPLOY.md](DEPLOY.md).** בלי הגדרות ענן, הכלי רץ מקומית כמו קודם, בלי התחברות.
